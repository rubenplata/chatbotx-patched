# ChatbotX Patched

An extensible, open-source conversational AI and messaging automation platform built with TypeScript, Next.js, and modern agent workflows.

## Features

- **Omnichannel Support:** Integrations for WhatsApp, Telegram, Messenger, Instagram, and Webchat.
- **Visual Flow Builder:** Drag-and-drop conversational designer for building complex interaction trees.
- **AI Agent Integration:** Modular connectors for OpenAI, Claude, DeepSeek, and local LLM endpoints.
- **Modern Stack:** Built on TypeScript, Next.js, PostgreSQL, Redis, and Turborepo for production performance.

## Getting Started

### Prerequisites
- Node.js 18+
- pnpm
- Docker & Docker Compose

### Installation

```bash
git clone https://github.com/rubenplata/chatbotx-patched.git
cd chatbotx-patched
pnpm install
```

### Running Locally

```bash
pnpm dev
```
